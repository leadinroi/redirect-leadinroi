# Redirect LEADinROI

Página branca de redirecionamento com destino e atraso configuráveis pela URL.

## Uso

```text
https://redirect.leadinroi.com/?url=https%3A%2F%2Fexemplo.com&delay=0
https://redirect.leadinroi.com/?url=https%3A%2F%2Fexemplo.com&delay=0.1
https://redirect.leadinroi.com/?url=https%3A%2F%2Fexemplo.com&delay=10
```

- `url`: destino completo, começando com `https://` ou `http://`.
- `delay`: espera em segundos. Aceita ponto ou vírgula decimal.

A página não mostra texto, contador ou indicador durante a espera. Parâmetros ausentes ou inválidos mantêm a tela branca.
